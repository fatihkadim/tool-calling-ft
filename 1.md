# Tool Calling Fine-Tuning Benchmark

Aynı base model (Qwen2.5-0.5B) ve aynı görev (tool calling) üzerinde LoRA, QLoRA, DoRA ve
Full Fine-Tuning yöntemlerinin karşılaştırılması. AI Engineer roadmap'inin Ay 2 projesi.

## Amaç

> "Modeli fine-tune ettim." demek yerine:
> "Aynı model ve aynı görev üzerinde dört fine-tuning yöntemini karşılaştırdım; tool selection
> accuracy, argument accuracy, JSON validity, VRAM, eğitim süresi ve inference latency'yi ölçtüm."

## Model

Qwen2.5-0.5B (base, instruct değil — fine-tuning etkisinin net görülmesi için)

## Dataset

NousResearch/hermes-function-calling-v1 (huggingface.co/datasets/NousResearch/hermes-function-calling-v1)
— ~2-4k örneklik bir subset. Single-turn tool call + "tool gerekmeyen" negatif örnekler dahil.

## Karşılaştırılan Yöntemler

1. LoRA
2. QLoRA
3. DoRA
4. Full Fine-Tuning

## Eval Metrikleri

- Tool selection accuracy
- Argument accuracy (field-level exact match)
- JSON validity rate
- Invalid tool call rate
- Unnecessary tool call rate
- Inference latency (tokens/s)
- VRAM kullanımı, eğitim süresi, trainable parameter sayısı

## Proje Yapısı

```
configs/            Her fine-tuning yöntemi için ayrı YAML config
data/raw/            Ham dataset (git'e commit edilmez)
data/processed/       İşlenmiş train/val split (git'e commit edilmez)
src/tool_calling_ft/
  data/               Dataset indirme, temizleme, formatlama, tool schema tanımları
  training/           Eğitim scriptleri (yöntem-agnostik, config ile parametrize)
  eval/               Eval harness + metrik hesaplama (reusable - Ay 3 quantization'da
                       ve Ay 6-7 agent projesinde tekrar kullanılacak)
  utils/              Logging, ortak yardımcılar
scripts/             CLI giriş noktaları (baseline eval, tüm deneyleri sırayla çalıştırma)
tests/               pytest - eval harness'in doğruluğunu test eder
reports/             Üretilen tablolar, plotlar, final rapor (git'e commit edilmez)
notebooks/           Colab/keşif notebook'ları
```
